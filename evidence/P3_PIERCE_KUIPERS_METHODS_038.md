## What changes after reading the methods

The missing **Pierce-Kuipers full-method access dependency is closed**. The earlier description of this source as methods-unread remains an accurate historical record of checkpoint036, and is superseded for subsequent decisions by this supplement.

PK97 is more consequential than a generic active-perception citation. Its implemented learning process constructs sensor structure, effect-grounded control primitives, candidate sensory features, local state variables, and feedback behaviors. A broad claim that this programme newly introduces acquisition of useful descriptions and procedures from initially uninterpreted interaction would therefore be untenable relative to this prior work. This is primary prior-art evidence for the broad acquisition proposition; it is not a finding that N4 as specified is an exact implementation of PK97.

The full paper does **not** establish a reduction of N4's acquired action-word library, six-trial contrast predicate, FIFO experiment scheduler and physical-reset contract to the historical algorithm. It also does not rescue N4's weak downstream knowledge criterion. The positive pattern in N4 still need not restore the earlier response function, identify a latent state, or improve a future decision. The checkpoint036 analytical witness concerns that literal predicate and is unaffected by obtaining PK97.

## Method reconstruction

The following account derives from PK97, DOI above, accessed **2026-09-11**, with source hash recorded above. It separates implemented operations from proposed extensions.

1. **Learn sensor structure.** The input is a real-valued sensor vector and continuous motor-control vector with initially unknown meanings. During random motion, the learner estimates inter-sensor value differences and distribution differences; similarity groups are joined by transitive closure. Metric scaling plus relaxation assigns coordinates to a related sensor group. These coordinates are learned from experience, although the distance metrics, grouping procedure and geometric representation are supplied. The environmental continuity and adequate sensor sampling assumptions are substantive. See §§1-2, PDF pp. 2-14 / printed pp. 170-182.

2. **Learn a control basis.** The learner samples representative motor vectors, estimates average sensory-motion fields, obtains a principal-component basis, and matches basis effects to control vectors. A new continuous control interface is defined from the matched primitive actions. This is acquisition of an action representation from effects, rather than N4's composition of an already supplied finite action alphabet. Approximate linearity is a required modeling assumption. See §3, PDF pp. 15-21 / printed pp. 183-189.

3. **Construct and test features.** A supplied typed set of generators is recursively applied to existing features. It includes grouping, images, minima/maxima, tracking and scalar extraction. The learner tests candidate scalar features for predictable, action-dependent change. Its static model progresses from action-independent prediction to action-dependent prediction to context-dependent linear prediction. The implemented context-selection heuristic uses the image position associated with a feature; the general discussion of searching other context features is broader than the implemented heuristic. This distinction is explicit in §4.2.3, PDF p. 28 / printed p. 196. Feature generation and its typed search restrictions are in §4.1, PDF pp. 23-25 / printed pp. 191-193.

4. **Derive reusable feedback behaviors.** Local state variables define error signals against targets. Supplied proportional-integral templates instantiate homing behaviors using learned action-model coefficients. Open-loop behaviors maintain a feature approximately constant while moving; additional experiments estimate first- or second-derivative effects of other actions. These dynamic models instantiate proportional-integral or proportional-derivative feedback for closed-loop movement. A behavior carries output, applicability, termination and initialization functions. The designer supplies the control templates and target-selection rule; learning supplies the feature/action/context relationships. See §5, PDF pp. 29-36 / printed pp. 197-204, especially Figs. 13, 15 and 19. The implemented target is half a feature's maximum; optimal target selection is expressly outside scope (§5.1 footnote, PDF p. 30 / printed p. 198).

5. **Build a discrete interface.** Termination points of behaviors are matched to stored sensor vectors using a supplied Euclidean-distance tolerance. They receive view symbols; behavior executions produce view/action/view records. The final illustrated tour is **user-guided**, not an autonomous exploration result. The paper demonstrates the first three levels of its hierarchy, then explains how they could support topological and metric learning using additional methods. Treating that discussion as a demonstrated autonomous completion of the entire map-learning chain would overstate the result. See §§7-8 and Fig. 29, PDF pp. 47-48 / printed pp. 215-216.

PK97 sources for the table are §§2-8 and Appendix A, PDF pp. 7-48, 56-57 / printed pp. 175-216, 224-225; DOI and source hash above. N4 is the frozen specification identified above.

**Substantive differences versus tuning.** A correlation threshold, feature-depth bound, controller gain or number of sampled motor vectors is a parameter of PK97. None of those settings installs N4's finite-word crossed-trial relation. Conversely, increasing N4's word bound or repetition count does not give it continuous sensory geometry, regression or closed-loop controller synthesis. An adapter could encode one system inside another, but its state, semantics, interaction requirements and compute would need to be specified and charged. No such adapter or action-by-action equivalence has been demonstrated here. Structural difference alone is also insufficient for a novelty claim: changes can be unimportant, and other prior methods may be closer.

One particularly relevant boundary appears in §6.7, PDF p. 46 / printed p. 214: learning **composite primitive actions** is proposed as future work for cases in which a needed effect requires an action sequence. It would be incorrect to cite that proposal as evidence that the implementation already learns N4's library of literal action words.

## Retention, reuse and the funded objective

PK97's §6.2 moves the simulated robot to a T-shaped room, erases the static/dynamic action models and learned behaviors, retains the sensorimotor model, and relearns the control level. Section 6.3 then moves it into an empty room while preserving both the sensorimotor model and behaviors. These are useful, bounded demonstrations of representation reuse and behavior transfer. They are **not** a matched test of retained versus erased representations, delayed recall under interference, recovery of the deleted models, or open-ended recombination after an unforeseen demand. See PDF pp. 39-41 / printed pp. 207-209; the figures are illustrative traces, and their performance was not reproduced here.

**PI interpretation:** the source strengthens the diagnosis that useful acquired intermediate representations can support subsequent learning and reuse, while narrowing any claim that the principle itself is new. It also shows what a stronger downstream bridge than N4's endpoint predicate looks like: learned variables participate in executable control and subsequent navigation. That is a reason to demand an explicit future-use criterion from the present programme. It is not evidence that the particular historical representation or N4 repairs the whole funded problem.

## Historical constraints and what remains in 2026

PK97 documents computational and methodological limits; it does **not** document that the field abandoned the approach, nor why any such abandonment occurred. A later [author-group bibliography](https://www.cs.utexas.edu/~qr/robotics/papers.html), accessed **2026-09-11**, lists follow-up work on learning from uninterpreted experience and the hierarchy. This is evidence of continuation, not a full history or a 2026 implementation survey.

The original failure experiments are specific. The narrow-room experiment distorts the inferred sensor arrangement and misidentifies the action basis; the circular-room experiment fails to identify usable local state variables because the available prediction/context machinery does not find the requisite predictable relationship. The paper also identifies insufficient exploration, overgeneral feature generation, poorly sampled sensors, feature-language limits and cascading stage failures. See §§6.4-6.7, PDF pp. 40-46 / printed pp. 208-214. These are sources of failure reported by the authors, not retrospectively inferred social explanations.

Appendix A, PDF pp. 56-57 / printed pp. 224-225, explicitly exposes potentially exponential feature/controller construction, sensor pair computations and unknown exploration duration to convergence. Its complexity accounting is not N4's retained-byte and arithmetic-bit accounting. I do not silently repair apparent label inconsistencies in the appendix or use them to claim a runtime ratio.

**PI inference for 2026:** greater compute can be allocated to broader feature/model search, repeated simulations and more thorough sampling. It cannot by itself remove a wrong model family, guarantee informative encounters, create a physical reset, turn a supplied template into a learned one, or ensure that an acquired contrast answers a future question. The source supports revisiting measurable restrictions, especially the narrow context heuristic and sequential failure propagation. It does not support the story that a general solution was discarded solely for lack of compute and now becomes valid by scaling it. No current hardware benchmark, later-method performance claim or universal cure is asserted here.

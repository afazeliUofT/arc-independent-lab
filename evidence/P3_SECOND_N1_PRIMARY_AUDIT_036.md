## Finding and remaining claim

N1 belongs to established constructive representation and history-state learning families. It is **not the inspected Drescher mechanism or McCallum U-Tree verbatim**: its learned state is a bounded Boolean function of retained observations/actions, and its selection objective is global raw conflicting-pair separation. The exact objective has a simpler description than either named agent: generated-column, append-only greedy coverage of cross-outcome transition pairs. Section 3 proves that correspondence, including candidate generation, retained prefix, prediction counts, interruption, and costs. This is an exact functional decomposition of N1, not a claim that a historical publication implemented its entire interface.

The defensible residual proposition is narrow: **this particular finite grammar, irreversible online selection schedule, count reader, and explicit persistence/resource contract might be a useful combination for making acquired history usable in later predictions**. Its first publication, useful out-of-sample acquisition, transfer after world changes, and recombination benefit are unestablished. Merely differing from U-Tree's reward objective does not establish those claims. A four-episode witness below shows that positive N1 gain need not mean improved predictive information even on its retained sample. These conclusions are analytical comparisons with the sources and frozen operation, not efficacy findings. [N1 specification, accessed 2026-09-10](https://github.com/afazeliUofT/arc-independent-lab/blob/17bd0df7a4d60f6ddfcffefc73049b1471a5ffd1/docs/P2_SECOND_OPERATION_SPECIFICATIONS_035.md); primary scopes below.

## 2. State, input, update, allocation, reset and cost mapping

### 2.1 N1's supplied and acquired objects

The following is a contract extraction from [N1 and the shared specification, accessed 2026-09-10](https://github.com/afazeliUofT/arc-independent-lab/blob/17bd0df7a4d60f6ddfcffefc73049b1471a5ffd1/docs/P2_SECOND_OPERATION_SPECIFICATIONS_035.md), not a new proposal.

| Aspect | Supplied/fixed | Encounter-dependent state or operation |
|---|---|---|
| Input | Categorical observation fields/types/order; primitive action alphabet/order; boundaries; declared observation space `O`; external action/observation stream | Completed ordinary transitions and their before-histories enter `T`. No reward, latent state, finished world-model set or correct predicate enters. |
| Language | Finite `W,S,K`; equality leaves over same-type lag terms/constants; `NOT,AND,OR`; serialization and missing-value semantics | Only encountered tokens activate constant leaves. Selected executable tests `Phi` depend on conflicts; the logical operators and history terms are not learned. Previously selected predicates are not new primitive grammar leaves. |
| Prediction state | Key form `(current observation, Phi(history), action)`; add-one formula | Counts of observed next observations for each active key; logged pre-observation predictions; selected feature vector and empirical status. |
| Construction | Enumerate all well-typed trees up to `S`; global gain/size/serialization preference | Append the largest-positive-gain test; recompute keys; repeat. Never retract a chosen test or delete contrary examples. |
| Allocation | `B_env,B_comp,B_mem`, serialized calls, reservation rules | Search passes/cursors, pair witnesses, spent work and bytes. N1 does not select an experiment; an outside stream or N3 does. |
| Physical/episode boundary | RESET is logged/charged, outside primitive supervised transitions; lags do not cross boundaries | Boundary observation starts a new before-history. Active empirical tables are archived/cleared on a declared new block; old records keep block provenance. Predicate syntax may be retained as a proposed reusable function. |
| Agent discontinuity | Persistent fields survive; only volatile call stack/incomplete local computations clear | Retained evidence, predicates and valid resumable state remain usable. Deleting a persistent field is another ablation, not the reference reset. |
| Cost/status | A declared accounting convention and bounds; no free oracle | Direct complete construction cost `O(K P n^2 S)` plus count rebuilding. All histories, values, syntax, witnesses and archives count. Incomplete required rebuilding blocks prediction. |

The wording “may retain” syntax at a new block is permissive; a fully executable later design must fix that policy. Exact reset comparisons below preserve the same chosen policy. This does not affect the active-block algebraic identity.

### 2.2 Drescher: actual state construction, but a different learned object

Drescher supplies sensory items, primitive actions and goals. Learned schemas have context/action/result components with reliability and per-item extension statistics. Marginal attribution spawns context/result extensions. An unreliable but locally consistent host can create a synthetic item, whose present value is maintained by trials, persistence and learned schema evidence. D87's implementation lacks synthetic items and composite actions; its specification includes them. Its schema–item cross-connectivity is a stated cost. [D87, pp.291–294, accessed 2026-09-10](https://cdn.aaai.org/AAAI/1987/AAAI87-052.pdf).

| N1 object | Drescher counterpart | Exact-mapping result |
|---|---|---|
| Observed categorical fields and actions | Supplied sensory items and actions | Interface family overlap; translating categories into item tests costs representation work. |
| `Phi` expression and Boolean evaluation | Synthetic-item definition plus maintained current state | N1 recomputes a total bounded-history function; a host-success condition and its maintained estimate are separate objects. |
| Raw `T`, conflicting pairs, count keys | Schema reliability/extension statistics | No literal identity with N1's retained-row global gain. |
| Global next-test selection | Local schema extensions/item creation | Changing a threshold does not replace the construction operation with the N1 grammar and global pair objective. |
| External action stream | Schema/goal activation machinery | Comparing only description learning requires holding the actual acquired trace fixed. |
| Declared archive/volatile reset and cap statuses | No identical API established in the inspected account | Add an explicit matched wrapper; do not attribute N1's contract to Drescher. |

**Concrete state/history distinction.** Take a permitted learned synthetic item with a learned persistence duration exceeding `W+1`. After successful versus unsuccessful host activation, append the same `W+1` ordinary observations/actions without newer item evidence and before the duration expires. The documented maintenance states can differ. N1, with identical final permitted lag terms and identical learned `Phi`, evaluates every test identically. This is a conditional maintenance-state witness, not a claim that both states must be reached from an empty learner by an unspecified number of trials. [D87, p.293, accessed 2026-09-10](https://cdn.aaai.org/AAAI/1987/AAAI87-052.pdf); N1 deduction.

This distinction is not an assertion of greater generality for N1. On a finite bounded horizon, a sufficiently large Boolean language can encode many maintained-state functions. Conversely, setting a timer shorter than `W` can remove this witness. Thus **representation overlap is real**; the different construction/update rules, rather than that one parameter comparison, prevent identification with the inspected named method. No mature-Drescher claim here relies on a duration-only characterization: the previously read dissertation explicitly includes predictive updates, evidence priorities and an Unknown state. [D89, §3.4.3 pp.125–127, original access 2026-09-06, prior account reread 2026-09-10](https://dspace.mit.edu/handle/1721.1/77702).

### 2.3 U-Tree: the strongest history-state comparator

U-Tree records a linked action/observation/reward instance chain; leaves partition histories by perceptual dimension and lag. Learned leaf Q-values and empirical transitions support value iteration. Every `k` steps it tests candidate fringes, bounded by history index `h` and depth `z`, using Kolmogorov–Smirnov comparisons of return distributions; the first qualifying split is installed and testing resumes. Action choice is greedy with random exploration. Instance eviction is optional. [M96/97, §§7.1–7.3 pp.85–94 and §7.6 p.114, accessed 2026-09-10](https://urresearch.rochester.edu/fileDownloadForInstitutionalItem.action?itemId=678&itemFileId=816).

| Field | N1 | U-Tree mapping and boundary |
|---|---|---|
| Inputs | Observation/action history, no reward | Same sensor/action information **plus scalar reward**. Neutral reward may be supplied for a matched descriptive contrast; answer-bearing reward must not be introduced. |
| Retained experience | `T` and permitted before-histories | Instance chain; select its no-eviction option when matching retained evidence. |
| Acquired description | Ordered global Boolean tests | Tree leaf partition from lag/dimension splits; compile tests to a tree only with the associated syntax/size cost. |
| Readout | Next-observation counts/distribution | Q-values, policy and empirical leaf transitions; replacing their target changes the learner. |
| Update objective | Maximum global unresolved-pair coverage | Local significance test and first qualifying fringe; no single significance threshold implements N1's ranking. |
| Allocation | All candidates per completed pass, at most `K` tests | Every `k` environment steps, fringe depth/history limits; these match search effort only after actual work is counted. |
| Reset | Explicit blocks, typed MISSING, archive and incomplete statuses | Those exact boundary/status semantics are not specified in §§7.1–7.3; they require a matched wrapper. |
| Cost | Candidate generation, evaluations, pair counts, rebuilding and bytes | Source's unpruned fringe count is `(h(|D|+1))^z` per leaf; instance routing, statistical tests, planning and stored nodes also consume resources. No equal-runtime conclusion follows. |

Source for the U-Tree column: [M96/97, pp.89–94, especially algorithm steps 2–5 and equation (7.9), accessed 2026-09-10](https://urresearch.rochester.edu/fileDownloadForInstitutionalItem.action?itemId=678&itemFileId=816). Other-column statements are frozen-N1 deductions.

**Concrete cold-start comparison.** Use two episodes: `0,b,0,a,0` and `1,b,0,a,1`, where the alternating entries are observations and issued actions. Give U-Tree reward zero on every transition and its root a uniform initial action value (zero suffices). N1 with `W>=1`, sufficient syntax/feature capacity and completed computation finds a positive-gain lag-one test for the two `a` transitions. U-Tree has one leaf; every instance has the same return statistic, so a proper significance test finds no difference and the leaf does not split. Repeating the episodes does not create a return difference. N1's different behavior follows from its chosen prediction target, not from a new capability to retain or inspect history. [N1 specification, accessed 2026-09-10](https://github.com/afazeliUofT/arc-independent-lab/blob/17bd0df7a4d60f6ddfcffefc73049b1471a5ffd1/docs/P2_SECOND_OPERATION_SPECIFICATIONS_035.md); [M96/97, pp.92–94, accessed 2026-09-10](https://urresearch.rochester.edu/fileDownloadForInstitutionalItem.action?itemId=678&itemFileId=816).

Changing U-Tree's lag/depth limits, discount, test frequency or significance level does not manufacture differing return samples in this witness. Supplying outcome-coded reward changes the supplied objective; replacing the test with raw pair gain changes the algorithm. Equally, a finite Boolean history test can be represented by a sufficiently expanded decision tree, so a Boolean-vs-tree representational contrast alone would be a weak novelty argument. U-Tree already searches conjunctions in a multi-level fringe; it must not be weakened to a single-feature-only comparator.

### 2.4 Rewardless schema prediction closes the obvious escape

HI04 supplies discrete sensors and actions; it learns schemas by action/effect counts and reliability-based context refinement. When refinement cannot suffice, synthetic items represent host success conditions; later host outcomes label past item state, enabling predictive maintenance. Evaluation uses random actions and the most reliable applicable schema for each sensor, with persistence fallback. Its speech implementation disables synthetic items and limits/prunes schemas. [HI04, §§2–3, accessed 2026-09-10](https://proceedings.neurips.cc/paper/2004/file/18bb68e2b38e4a8ce7cf4f6b2625768c-Paper.pdf).

The state mapping is therefore `Phi` to synthetic-item definitions/current estimates, `T`/counts to schema statistics, and N1's outcome distribution to per-sensor schema predictions. These are correspondences, not equal updates: the supplied syntax, creation criterion, retroactive label use, prediction aggregation and allocation differ. Physical-block archives and cap/interruption semantics again need explicit matching; the paper does not specify N1's contract. A total finite-history Boolean function cannot silently be identified with a recursively maintained synthetic sensor. Conversely, adding N1's full histories/grammar/gain to HI04 would be an algorithm replacement, not mere tuning. [HI04, §§2–3, accessed 2026-09-10](https://proceedings.neurips.cc/paper/2004/file/18bb68e2b38e4a8ce7cf4f6b2625768c-Paper.pdf); comparison derived from N1.

Thus rewardless construction of a predictive description is already a primary-method antecedent. The stronger objection to N1 is its exact selection rule, examined next, rather than its departure from reward maximization.

## 3. Exact generated-column discernibility/coverage decomposition

Pawlak–Skowron define pairwise attribute difference sets, decision-relative discernibility and approximate reducts preserving a chosen fraction of entries. Their ordinary formula omits empty entries; the basic decision-relative presentation starts with consistency. They also discuss creating a new attribute from existing attributes. Their method is not N1's exact online heuristic, and an arbitrary reduct/positive-region criterion must not be relabeled as N1's gain. [PS07, §§2.1–2.2 pp.43–47, accessed 2026-09-10](https://bcpw.bg.pw.edu.pl/Content/1970).

**The following equality is an original audit derivation from the frozen operation.** At a fixed active-block transition-table version let row `i` contain history `h_i`, current observation `o_i`, issued prediction action `a_i`, and observed result `y_i`. Preserve separate acquisition identities even for duplicate rows. Define:

\[
E=\{\{i,j\}:i<j,\ (o_i,a_i)=(o_j,a_j),\ y_i\ne y_j\}.
\]

Generate candidate columns using **the same** finite grammar, encountered-token inventory, type checks, size bound and serialized syntax identities as N1. Column `p` has value `p(h_i)` in row `i`. Define its covered pairs and the selected coverage:

\[
C_p=\{\{i,j\}\in E:p(h_i)\ne p(h_j)\},\qquad
U_\Phi=\bigcup_{\phi\in\Phi}C_\phi.
\]

Two rows have the same full N1 key exactly when their base keys agree and no selected predicate separates them. Consequently:

\[
\text{conflicts}(T,\Phi)=E\setminus U_\Phi,\qquad
\operatorname{gain}(p)=|C_p\setminus U_\Phi|.
\]

N1's committed feature addition is therefore exactly: choose a column covering the greatest number of **currently uncovered** required pairs; break ties by syntax size and serialization; retain that column and continue. This is greedy coverage on a decision-relative difference table generated from historical expressions. It is not conditional entropy, mutual information, a minimum-cardinality reduct, or a guarantee of future prediction improvement. The equivalence follows by membership of each pair, without importing a statistical or optimization theorem.

| Frozen N1 field/event | Exactly matched construction |
|---|---|
| Empty `T,Phi` | Empty row store and selected-column prefix |
| New completed transition | Append row; add its same-base/different-outcome pairs; update outcome counts |
| Newly encountered constant token | Activate exactly the newly legal grammar columns; their enumeration/evaluation is charged |
| Existing selected `Phi` | Keep the identical ordered prefix; never recompute a fresh optimal/batch reduct |
| Positive-gain pass | Maximize uncovered pair coverage with the same complete-pass and tie rules |
| Residual conflict | Retain the pair even if its difference set is empty; never hide inconsistency by omitting that row |
| `K`, grammar or compute exhaustion | Return the same distinct status with the same residual witnesses |
| Search interruption | Keep the same version-tagged cursor; commit no partial-pass choice; reject stale resumptions |
| Prediction | Group rows by the same base key and selected column vector; use exactly `(count(y)+1)/(n_key+|O|)` |
| Required count rebuild unfinished | Return `COMPUTATION_INCOMPLETE`, not a numeric answer |
| Volatile reset | Preserve the same row store, columns, counts, cursors and spent-work records |
| New world block | Archive/clear precisely the same empirical records; preserve or clear syntax according to the same fixed block policy |
| Resource accounting | Generate/evaluate columns from the actual retained history; retain all declared witnesses, logs and archives; use the same reservation/stop protocol |

Every entry in this table is a restatement of the frozen operation through the pair identity. At each serialized admitted event, equal row stores and selected prefixes imply equal candidate values, gains and committed choices; equal groups imply equal distributions/statuses. With identical boundary/cursor policies, induction gives equal observable output traces. **There is no distinguishing history for this constructed comparator.** This is stronger than a similarity analogy but narrower than historical whole-package identity. [Frozen N1/shared contract, accessed 2026-09-10](https://github.com/afazeliUofT/arc-independent-lab/blob/17bd0df7a4d60f6ddfcffefc73049b1471a5ffd1/docs/P2_SECOND_OPERATION_SPECIFICATIONS_035.md).

Important restrictions on the reduction:

1. The exact equality is **version by version, with the retained selected prefix**. Running ordinary batch selection from empty on the final table can select a different prefix; N1 never backtracks.
2. Candidate construction is not a free supplied-feature oracle. The comparator runs the same syntax generator and computes its values from the same permitted histories. The fact that the language can enumerate a test does not mean the test was given as a finished useful variable.
3. The base `(observation,action)` already separates pairs without spending one of `K` tests. A comparator that uses its feature budget to recover those supplied key fields is mismatched.
4. Keeping empty difference sets is necessary to reproduce unresolved evidence. Classical formulations that discard them cannot supply N1's report without an added inconsistency/witness channel.
5. Positive syntax-size tie-breaking is not a weighted objective trading arbitrary coverage against expression length. It applies only after equal integer gain.
6. Identical selection does not prove identical implementation complexity. Direct matched computation can use N1's `O(K P n^2 S)` scheme plus rebuilding. Indexed coverage may avoid materializing the full matrix; no free speedup or mandatory quadratic storage is asserted. Generated syntax, histories and arithmetic bit costs still count.

This establishes family membership and an exact decomposition of the committed learning rule. It does **not** establish that PS07, or one earlier named algorithm, used the entire N1 grammar, online schedule, readout and stopping interface. That remaining priority question must not be turned into a claim that the underlying operation has no antecedent.

## 4. A diagnostic history: positive pair gain without predictive separation

Take `W=1`, categorical observations `O={0,1}`, primitive actions `{b,a}`, sufficient `S`, `K>=1`, and enough resources to finish every pass. Four separately bounded episodes arrive in this order:

| Episode | Initial observation | `b` returns | `a` returns |
|---|---:|---:|---:|
| 1 | 0 | 0 | 0 |
| 2 | 0 | 0 | 1 |
| 3 | 1 | 0 | 0 |
| 4 | 1 | 0 | 1 |

These are permitted N1 input histories; N1 alone does not require the deterministic physical-reset affordance imposed on N2–N4. All `a` transitions have current observation 0 and preceding action `b`. Their only varying available history information is the lag-one observation `p` in `{0,1}`. All `b` outcomes are 0, and their different action key prevents them from conflicting with `a` transitions.

After the second `a` transition, the conflicting pair has identical permitted terms, so no predicate can separate it. After the third, there are two conflicting `a` pairs: the first two remain indistinguishable, while the pair joining episodes 2 and 3 has different `p`. A test inducing the `p` partition has gain 1 and is selected. The particular serialized winner can be an equivalent or complemented test; **every positive-gain candidate induces that same two-group partition** on these histories.

After episode 4, each selected key has one outcome 0 and one outcome 1. Its empirical distribution and add-one prediction are both `(1/2,1/2)`, exactly the unsplit table's prediction with two of each outcome. Retrospectively, the unsplit table has four cross-outcome pairs and the selected partition leaves two. Thus raw pair disagreement fell while conditional predictive distributions did not improve. The remaining two conflicts cannot be split by any allowed expression, since all permitted terms agree within each group. This is an algebraic witness, not a noise experiment or a measured failure. [Derivation from frozen N1, accessed 2026-09-10](https://github.com/afazeliUofT/arc-independent-lab/blob/17bd0df7a4d60f6ddfcffefc73049b1471a5ffd1/docs/P2_SECOND_OPERATION_SPECIFICATIONS_035.md).

The issue is the unnormalized objective: fragmentation can remove cross-group opposite-label pairs even when every group has the same label proportions. Increasing `S`, `W`, `K` or compute does not make raw pair coverage an information-gain criterion. Choosing a different criterion would be a new specification. The witness does not show that N1 never learns a useful feature, nor that its authors promised monotone predictive improvement; it identifies precisely what a positive construction log can and cannot certify.

## 5. Historical obstacles, 2026 relevance and continuation

**Drescher.** The original Lisp-machine implementation slowed as schemas accumulated; the later dissertation documents memory exhaustion, restricted microworlds and incomplete advanced acquisitions. These are actual implementation obstacles, not evidence of a causal account of abandonment. The previously inspected dissertation also identifies proliferation and the absence of a sufficiency demonstration for its controls. No evidence read here establishes that the construction premise was refuted or that scarcity explains later uptake. [D87 p.294, accessed 2026-09-10](https://cdn.aaai.org/AAAI/1987/AAAI87-052.pdf); [D89 pp.94, 129, 143, 150–151, 204–209, original access 2026-09-06, prior account reread 2026-09-10](https://dspace.mit.edu/handle/1721.1/77702). **2026 inference:** more available hardware can change a fixed implementation's feasible scale; it does not remove cross-association growth or supply a missing learning route. No 2026 capacity or performance measurement was made.

**McCallum.** The author identifies costly fringe search, greedy non-optimal trees, limited history/conjunction depth, difficult reward discovery, loops, and ineffective exploration under aliasing. These are reasons to bound or improve the method, not documented reasons the research was abandoned. [M96/97, §§7.6 and 8.1 pp.113–116, accessed 2026-09-10](https://urresearch.rochester.edu/fileDownloadForInstitutionalItem.action?itemId=678&itemFileId=816). **2026 inference:** hardware can expand `h,z` and tested fringes; it cannot make a finite history window represent arbitrary memory across loops or make unavailable reward distinctions available. N1 changes the objective, but retains finite history and expensive representation search. It adds no experiment scheduler of its own.

**Discernibility/attribute construction.** The inspected author exposition reports hard reduct problems and heuristic approaches, rather than abandonment. [PS07, §§2–2.2, accessed 2026-09-10](https://bcpw.bg.pw.edu.pl/Content/1970). **2026 inference:** a larger machine can evaluate more grammar columns; it cannot convert sample consistency into identification of world truth, or positive pair gain into out-of-sample information. No specific modern solver benchmark is claimed.

**A concrete modern continuation, with its limit.** Lagriffoul's 9 May 2022 controller trains separate modal linear prediction models offline, over a supplied partition of continuous action parameters, and compares serial/interruptible control schemes. It does not implement online synthetic-item acquisition: developmental mechanisms are future work. This establishes continued schema-based embodied research, not a solution to N1's acquisition/retention/recombination demand. [L22, §§4–7, accessed 2026-09-10](https://www.frontiersin.org/journals/neurorobotics/articles/10.3389/fnbot.2022.836767/full). Its architectural critique is the author's argument; the small controller comparison is not evidence that every alternative architecture is biologically invalid or scientifically abandoned.

## 6. Programme interpretation and unresolved dependencies

For the programme's broad demand—acquire world knowledge, retain it through discontinuities and recombine it—the acquired N1 object is an executable description of already retained finite history. It is neither newly acquired external evidence nor an identified causal state. Preserving `T,Phi` through a volatile reset provides a declared storage channel that a comparator can also preserve; it is not yet demonstrated robustness to loss of persistent knowledge. On a new physical block, old empirical tables cease to be current evidence. Boolean composition in a supplied grammar does not alone demonstrate recombination of separately acquired world knowledge in unobserved situations. These are limits of what the frozen component specifies, not claims that the wider programme is impossible. [N1/shared contract, accessed 2026-09-10](https://github.com/afazeliUofT/arc-independent-lab/blob/17bd0df7a4d60f6ddfcffefc73049b1471a5ffd1/docs/P2_SECOND_OPERATION_SPECIFICATIONS_035.md).

The appropriate later contrast therefore retains the complete acquired traces, uses the same generator and limits, matches actual construction/replay work, and compares the predictive use of a learned distinction against a same-budget history reader. Feature provenance and pair-count reduction by themselves are insufficient evidence.

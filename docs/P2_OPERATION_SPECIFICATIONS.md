# Phase 2 developed operations

PI specifications, 2026-09-06. Written after the raw population was frozen in `evidence/P2_GENERATION_FREEZE.json`. These are candidate operations, not validated repairs. No novelty comparison was used to reject an idea during generation. Nearest-method flags are a separate later section of `IDEAS.md`.

## Shared conventions

Every operation has an explicit interface. Supplied alphabets, hypothesis families, goals, representations and context boundaries count as prior structure. Calling a state variable learned does not explain how its input was obtained. A later experiment must expose or control each such dependency. The specifications below intentionally describe narrow mathematical objects precisely rather than claim an implemented general agent.

All tie breaks use a fixed lexicographic ordering of identifiers supplied before a run. Undefined or unsupported queries return a typed `unresolved` value; they do not acquire an arbitrary confident answer. Numerical tolerances, regularization constants, capacity bounds and evaluation thresholds remain design parameters to be chosen and frozen in Phase 3 before measurement. No candidate experiment is run in this phase. Cost symbols describe operations; they are not measured runtimes or affordability judgments.

## C1 — Preserve the alternatives that present evidence cannot distinguish

**Diagnostic target and generated origin.** B1: a training criterion selects one presently successful relation when different future consequences remain compatible with the evidence. Primary origin B1-01, with B1-23's executable descriptions and B1-06/B1-24's distinction between a world relation and an observation relation. The underlying move is retaining unresolved explanatory alternatives, not merely lowering confidence on one predictor.

**Interface and supplied structure.** Use a finite action alphabet A and finite observation alphabet O; their construction is outside this operation. Supply a finite, canonically ordered set H0 of deterministic executable transducers. Each h has a finite state set Qh, an initial-state subset Ih, a transition function Th(q,a), and an emitted observation Oh(q,a). No semantic factor names are required. H0 may contain explanations that assign a changed observation to different world or sensor processes, but inclusion of those alternatives is a declared modeling choice. This is not unrestricted causal-variable discovery.

**State.** A set S of live pairs (h,q), initially all h in H0 with q in Ih. Store each fixed program h once plus its surviving state identifiers. Also retain the fixed prior ordering and an `inconsistent` flag. No raw interaction archive or old target labels are needed for the update itself. Each pair represents an explanation and its state after the entire observed history.

**Inputs and update.** On the actual observed action a and subsequent observation o:

1. For each live (h,q), compute predicted Oh(q,a).
2. If it equals o, include (h,Th(q,a)) in Snew; otherwise remove that pair.
3. Deduplicate identical pairs. Replace S with Snew.
4. If Snew is empty, set `inconsistent` and return `unresolved`. Do not silently relax constraints, invent a new program, restart from H0 or select the least bad survivor.

The strict deterministic rule is the specified candidate. A noisy extension would be a different specified variant, not an implementation detail silently added after results. A fixed observation channel can be part of h; a noise-free comparison cannot establish robustness to arbitrary corrupt labels.

**Query and reuse.** Given a finite future action word u, simulate it from each live pair and return the set of predicted observation words. Agreement licenses that prediction under H0; disagreement remains explicit. If a task asks for a decision d from a finite set D, a supplied decision functional maps each predicted observation word to a loss. Return a decision only under an externally declared commitment rule; the operation's output remains the full alternative set. A downstream policy cannot be credited with this operation if it discards the alternatives and acts on the first surviving program.

**What changes and what stays unchanged.** This changes the content of the learned state and the query interface. It does not choose actions, enlarge H0, change the observation interface, supply a future goal schedule or protect model weights from arbitrary updates. A comparison that also changes the acquisition policy would test a package rather than this operation alone.

**Discontinuity.** Retain S and the program definitions across an episode/context clearing. For an explicit world reset, supply a fixed relation R_h(q) of allowed post-reset states and replace each live (h,q) with (h,qprime) for qprime in R_h(q), then deduplicate. Retain h; never repopulate an already empty inconsistent set from H0. A reset to compatible initial states is one declared R_h, not a default that ignores the observed history. Do not assume that an agent-memory reset and a world reset mean the same operation. Unknown reset behavior must itself be represented in H0 or cause unresolved predictions.

**Cost.** Let K be the number of live pairs and c be the maximum one-step program cost. Updating costs O(Kc), apart from deduplication. A length-L query costs O(KLc), with output storage proportional to the returned alternatives. Model definitions and current state pairs are persistent memory; constructing H0 may be vastly more costly and is not hidden in the update bound.

**How we would know it addressed B1.** Under identical evidence, supplied families and acquisition policy, a comparison learner commits to a relation that fits the record but fails under a warranted reuse. This operation must retain the relevant alternative and make its disagreement available to the actual decision procedure before failure. Improved calibration alone is insufficient. If the useful explanation is outside H0, or every explanation makes the same wrong reuse prediction, this operation has not addressed the case. Correctness under all surviving programs remains relative to the supplied family, not proof of the true ontology.

## C2 — Choose experiments for the decisions their observations could change

**Diagnostic target and generated origin.** B2: current performance selects a history that omits an obtainable, later-relevant distinction. Origins B2-01, B2-02, B2-10, B2-12 and B2-14. The underlying move is changing action selection according to the realized value of possible evidence, including absence produced by earlier actions. Its representation and inference substrate are inputs, not an additional claimed invention.

**Interface and supplied structure.** Supply a finite belief over world states h with probabilities p(h), finite experiments E, and a finite family G of possible future decision problems with weights mu(g). Each experiment e is a bounded policy tree over permitted actions and observations, not an oracle intervention on a hidden variable. For every e, the substrate supplies a finite joint kernel Q_e(hprime,z|h) for the post-experiment world state hprime and observable transcript z, conditional on the current world state h. It also predicts costs and losses of future decisions. These models must include any observation opportunities changed by the learner's actions. An impossible-to-observe absence cannot be supplied as a hidden informative token.

**State.** Current p, current physical/latent state per hypothesis, the remaining interaction allowance, and the immutable definitions of E and G. Store a record of the chosen experiment, predicted transcript alternatives and the actual transcript for auditing. This operation need not generate or repair its predictive models. C1 could provide a substrate after an explicitly supplied prior, but C2 must also be specifiable with a fixed external substrate so their contributions can be separated.

**Exact selection rule.** For each e and possible transcript z, compute P(z|e) = sum over h,hprime of p(h) Q_e(hprime,z|h). For P(z|e)>0, form p_e(hprime|z) = [sum over h of p(h) Q_e(hprime,z|h)] / P(z|e). Zero-probability transcripts contribute zero to the prospective sum. If an actual transcript has zero predicted probability, return model-inconsistent rather than fabricating a posterior. Let

R(e,z) = sum over g of mu(g) times min over permitted d of sum over hprime of p_e(hprime|z) times L_g(hprime,d).

Let R0 be the corresponding expected Bayes decision loss if the agent ends experimentation now. The criterion is

V(e) = R0 - sum over z of P(z|e) R(e,z) - lambda times expected interaction/resource cost of e.

Include `stop`, with value zero and no experiment, in E. Choose the feasible member with maximum V, breaking ties by fixed ordering. Feasible here means it obeys the explicit interface and remaining allowance, not that the PI has screened the research candidate for practicality. Every executable branch of a feasible experiment must fit within the hard remaining interaction allowance; an expected cost alone does not satisfy that bound. Execute only the selected experiment, charge its realized interaction cost, and condition on the actual transcript. Stop that experiment and return model-inconsistent on an out-of-model transcript, preserving the actions and cost already incurred. Replan thereafter only if the model remains consistent. The loss is evaluated in the resulting world state, so an experiment that changes the world is not incorrectly treated as a free observation of its previous state.

**No privileged future task.** G and mu are an explicit prior over future demands, not the realized future evaluation schedule. If the actual task is disclosed at decision time, use the corresponding g then. Acquiring arbitrary information against completely unrestricted unknown future goals is not promised. A candidate implementation cannot inspect withheld tasks to construct G.

**Feedback and biological constraint.** A restoration or withdrawal action is informative only if the actual predictive family distinguishes its transcripts under alternative causes of absence. The rule does not automatically reward every surprising event, nor presume that masking occurred. Earlier action products enter the predicted observation process as state if they matter; ignoring them can make the estimated value of an experiment wrong.

**What changes and what stays unchanged.** This changes which permitted experiment is selected and therefore which data actually arrive. It leaves the predictive family, parameter update, memory allowance and eventual decision loss unchanged. Its gain must not be attributed to acquisition if it receives better models, extra outcomes, more interaction or a revealed future goal.

**Discontinuity and cost.** Persist p and relevant experiment outcomes through the declared memory channel; apply the declared world reset to each hypothesis state. With K current states, Kprime reachable post-experiment states, J experiment policies, Z possible transcripts per policy, G future problems and D decisions, direct enumeration costs O(JZ(KKprime + GKprime D)) when each kernel entry is available at constant cost, plus kernel construction/simulation cost; all symbols are bounds on supplied finite objects. Tree construction, model inference and growing histories are separately charged. No laptop-sized implementation is assumed.

**How we would know it addressed B2.** The chosen experiment must generate an observation that distinguishes the relevant alternatives and changes a later decision, while an equal-allowance comparator's actual record does not. Replaying the acquired record into the same fixed downstream learner should account for the gain. If success comes from a different downstream inference rule, extra goal disclosure or changing the physical world into an easier task without acquiring the alleged distinction, that is a different causal explanation. A computed high V that produces no useful evidence is not evidence of repair.

## C3 — Learn a translation from the current representation to an old query interface

**Diagnostic target and generated origin.** B3: useful historical structure survives but its old response path is no longer aligned with the learned representation. Origins B3-01, B3-03 and B3-07. The move is adapting access to a changed representation, while keeping the underlying new-learning updates fixed. It is separate from the requested observer diagnostic and is not selected on that diagnostic's result.

**Interface and supplied structure.** Supply an encoder f_theta(x) in R^d and a previously learned matrix readout W in R^(d by p) for a declared old query family, with any final decision postprocessing fixed. An explicit boundary identifies when this interface is established. The candidate does not discover that boundary, decide which old relation remains true, or construct the old semantic readout. Select n unlabeled anchor inputs by a deterministic rule over observations available before the boundary, fixed in advance. No held-out probe or evaluator answer may become an anchor.

**State at the boundary.** Store the anchors X=(x_i), their reference activations r_i=f_theta_boundary(x_i), the old readout W, and a translation T initially equal to the identity. R is the matrix with rows r_i. These activations can encode old answers: they are an explicitly counted history-bearing channel, even though no external target labels are stored. The operation must never be described as recovery from current weights alone.

**Update rule.** Continue the original encoder training unchanged. At a fixed refresh schedule, compute current anchor activations Z with rows f_theta(x_i), then set

T = argmin_T ||ZT-R||_F^2 + lambda ||T-I||_F^2,

with a fixed positive lambda. Equivalently solve (Z^T Z + lambda I) T = Z^T R + lambda I. The positive regularizer defines a unique solution; do not silently switch to a different alignment or tune lambda using evaluation answers. On an old query x, the response vector is f_theta(x) T W, followed by the fixed decision postprocessing. The new task continues to use its original response path.

**What changes and what stays unchanged.** Only the old query's conversion from current features changes at refresh. The encoder update rule, new-task reader, old W, anchors and R stay fixed within this candidate instance. Anchors that the changing world no longer makes meaningful are a stated failure condition, not grounds to replace them from a held-out set. Updating W as well would be another operation.

**Discontinuity.** Clearing transient context retains X, R, W and T if those are the declared channel. If they are erased, the candidate has not retained its required state. A world reset does not automatically invalidate them, but changed observation semantics can; a successful translation of fixed inputs is insufficient to establish validity of their old world interpretation.

**Cost.** A refresh uses n encoder evaluations, O(nd^2+d^3) dense linear algebra and O(nd+d^2) numeric memory, in addition to raw anchors and W. A query adds O(d^2) work before the fixed O(dp) matrix reader. Faster solvers, diagonal approximations or compressed anchors would be specified variants. Resource comparisons must charge the reference activations and extra evaluations rather than counting only model parameters.

**How we would know it addressed B3.** From the same post-update encoder, with the same permitted historical inputs and equivalent computation, a corrected interface should restore a still-valid relation whose information the current representation continues to carry. Gains supported only by interpolation of cached old answers do not establish latent access. Useful checks include held-out old inputs beyond the anchors and controls where the relevant encoder distinction is actually removed; fixed-input anchor agreement alone does not suffice. A linear translation can fail after nonlinear loss or a rank collapse. The operation neither proves nor guarantees that the distinction survived.

## C4 — Construct a rule's scope from positive and contradictory encounters

**Diagnostic target and generated origin.** B1: a useful local regularity becomes a broad relation without preserving the observations that distinguish its valid scope. Origins B1-03, B1-12, B1-14 and B1-24. Unlike C1's retained alternative world descriptions, the move here is constructing an explicit conditional boundary for a particular reusable prediction from actual contrasts.

**Interface and supplied structure.** An experience is (x,a,y,t), with observable descriptor x, action a, observed outcome y and provenance tag t. The tag identifies a declared observation process or intervention type; it is not a hidden truth label. Supply a finite library A of total Boolean tests on x, including any relational tests the learner can evaluate. Conditions may use either polarity of each test; a condition containing the seed uses only the polarity true at that seed. Supply a target function y=F(x) for one proposed rule, a seed encounter on which it held, and a maximum conjunction length k. F, A and their construction are explicit upstream inputs. This operation constructs the rule's scope, not the target relation from nothing. Contrasts cannot reveal distinctions absent from A.

**State.** For each proposed (F,a,t,seed), keep all admitted positive encounters P and contradictory encounters N, and a condition C that is a conjunction of at most k atoms from A. Admitted means same action and provenance tag, with all necessary observed fields present. An unobserved outcome is unknown and enters neither set. The original seed remains in P. Positive and negative refer only to the observed relation y=F(x), not to the reward or desirability of y. Storing all witnesses is the exact candidate; bounded compression is a separate variant.

**Update rule.** On an admitted observation, add it to P if y=F(x), otherwise to N. Enumerate all conjunctions of length at most k that contain the seed and exclude every member of N. Of those, choose the condition covering the largest number of P; break ties by shorter length, then the fixed atom ordering. If none exists, mark the rule unresolved. Do not discard a contradiction, increase k or invent a predicate solely to prevent this outcome.

If no admissible condition exists, first compare the full Boolean test signature of the seed with each negative. If any matches, return `unresolved: observational_aliasing` with the seed and the first such negative: no conjunction of the existing tests can separate that pair. If none matches, return `unresolved: length_bound` with the witness set: separation exists using the full seed-compatible conjunction but not within k. Individual pairs can be separable even when the collection requires a longer conjunction; do not misdiagnose this as a missing observable variable. Only the demonstrated aliasing case requests a new predicate from an upstream description learner. This operation does not implement that learner, increase k or expand the atom library within the instance.

**Use and composition.** The rule licenses F(x) only when C(x) holds and its action/provenance match. If several applicable rules disagree, return unresolved rather than selecting by reward frequency. An ordered sequence of rules can be composed only if each succeeding condition is established by available observations or warranted outputs of preceding rules. Unestablished conditions stay unknown. Passing these checks is empirical compatibility within the description language, not proof that the relation is a causal invariant beyond observed support.

**What changes and what stays unchanged.** This changes the selection and use of a conditional domain, preserving contradictions when defining it. It does not change actions, reset rules, F, the observation channel or the atom library within the instance. Separating provenance stops unlike evidence from silently entering the same support set, but does not infer which sensor was wrong. Where trustworthy labels are unavailable, the unresolved attribution remains an upstream question, as the biology pass requires.

**Discontinuity and cost.** Persist F, atom definitions, C, the seed and witness sets. If an old rule becomes false after a world change, maintaining its condition does not make it valid. With m atoms, k as above and Nw witnesses, exhaustive refinement checks sum_{j=0}^k binomial(m,j) conjunctions, each over Nw witnesses; memory includes all witness descriptors. Approximation or witness eviction changes the candidate and must be named. This enumeration is deliberately specified despite its possible expense.

**How we would know it addressed B1.** With the same observed encounters and proposed F, ordinary selection uses a broadly rewarded relation outside its warranted scope, while preserving its contradictory witnesses leads to a condition that distinguishes the actual reuse cases. Merely refusing more predictions is insufficient: coverage, correct reuse and unresolved decisions must be visible together. If the selected condition is itself a training co-occurrence that fails under the intended rearrangement, the proposed cause remains. A missing observable atom or an untested branch cannot be repaired by asserting a narrower scope with no evidence.

## What the selection commits us to

The four specified operations span three broad causal families: relation selection (C1 and C4), evidence acquisition (C2) and expression/access (C3). Their controlled objects are alternative explanations, selected interactions, conversion into an old query interface, and conditional rule scope; they are not four independently established demands. C1 and C4 both concern relation selection but make different interventions: maintain uncertainty over complete executable descriptions versus construct the applicability of a proposed local prediction. They should be combined only if later evidence requires it. A combined gain would not identify which move mattered.

Other raw families remain visible and unrefuted: literal copies, external environmental memory, exhaustive physical exploration, inverse updates, distributed learners, active reacquisition and schema/predicate discovery. They were not developed in this bounded pass because the selected set spans different causal locations while keeping each operation specifiable. This is convergence after generation, not a finding that the remaining ideas are infeasible or inferior.

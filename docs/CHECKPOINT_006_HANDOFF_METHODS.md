# Checkpoint006: Phase2 continuation

Prepared from human approval commit `376455150af7b257809a56021431413b2e0c6293` in [arc-independent-lab](https://github.com/afazeliUofT/arc-independent-lab/commit/376455150af7b257809a56021431413b2e0c6293), accessed 2026-09-06. The final checkpoint manifest records the scientific scope after the science and state files are complete. This transport preparation does not itself establish completion of Phase2 or satisfaction of a scientific gate.

`scripts/checkpoint006_handoff.py` makes exactly four textual substitutions to the unchanged checkpoint005 helper: description, pinned base, checkpoint identity and backup directory. Syntax and equivalence after reversing those substitutions are recorded in `evidence/CHECKPOINT_006_HANDOFF_ADAPTATION.json`. The helper performs local inspection, backed-up application and staging, or complete index/direct-child verification. It performs no fetch, commit, push or authentication. Prior helpers and manifests remain unchanged.

The local builder `delivery/build_checkpoint006.py` accepts a root-approved JSON file containing explicit `new_paths`, `changed_paths` and a `scientific_status` description. It inventories every base file plus the declared additions, rejects undeclared changes and deletions, and preserves existing bytes and modes except for the explicitly approved changes. Parked ideas are handled only as opaque bytes during transport and cannot enter a changed payload. Private source directories, delivery files, fixtures and PDFs cannot enter a new or changed payload. The builder neither stages files nor commits or pushes. It must run only after the root has finished the science, ledger and state updates.

`state/CHECKPOINT_006.json` lists the complete intended public tree except itself. The ZIP's `HANDOFF.json` separately pins that manifest's bytes. In the complete manifest, `files` is a list of path/hash/mode records; in `HANDOFF.json`, `files` is a dictionary from path to old hash, new hash and mode. Keeping those schemas distinct avoids the previously encountered list/dictionary packaging error. Package hashes are delivered outside the archive to avoid self-reference.

Before delivery, the root must apply the actual final archive to a contained clone of the exact base using `core.autocrlf=input`, verify its complete staged tree against the manifest, and record the result separately. Syntax and source equivalence alone do not establish this final archive check. No actual-archive validation is claimed by this preparation note.

The human executes the real commit and push with normal visible Git authentication. An explicit full-SHA refspec stays on one physical line; a failed push leaves the verified local commit available for retry. Public readback must then verify the human commit against the checkpoint. The existing GitHub bridge provides durability; no credential collection or alternative upload route is introduced.

## Adopted syntax and information boundary

Equality leaves are ordered same-type term pairs, including both orientations and self equality, or a term followed by an encountered same-type constant. MISSING is a typed history value, not an additional encountered token constant. Within a well-typed equality the implementation uses the reserved value minus one; ordinary tokens are nonnegative. No cross-type equality is admitted.

AST constructors are EQ0, NOT1, AND2 and OR3. A term is `(0,type,field,lag)`; a constant is `(1,type,token)`. Observation type is0 and action type1. Numeric prefix tuples, with the fixed constructor arities, supply the explicit lexicographic tree tie order. EQ has Boolean size one; NOT adds one and AND/OR add one plus both child sizes. Literal trees remain distinct even if they calculate the same truth vector. There are38 leaves and3002 trees when all five constants of each type have been encountered. No binary codec is silently substituted for this numeric ordering.

RESET observations count as encountered observation tokens when received; RESET itself is not an N1 prediction action. An actually issued primitive action becomes an encountered action token. Proposed words and declared output alphabet membership do not alone supply encountered constants. A frozen snapshot retains its own inventory. Delayed validation is assimilated in chronological order after credit finalization; a later queued token must not enter an earlier transition's construction pass. The target chooser and its data are absent from043.

## N1 implementation contract

The complete literal syntax inventory is preserved in size/numeric-prefix order. The selected objective is exactly035's number of conflicting unordered transition pairs separated by the predicate. Grouped outcome masks calculate the same integer gain as literal pair enumeration: within a current-key group, `n0*n1 - sum_y n0y*n1y`. Each transition-table, selected-predicate and encountered-inventory version is explicit. Only a complete candidate pass may select its best positive predicate. Cursors retain completed work, versions and the next candidate; an interrupted candidate can be recomputed with its prior work still charged. Changed source versions invalidate a cursor. Required count rebuilds must match the actual table/Phi version; incomplete rebuilds return a nonnumeric status. A completed feature selection is retained even when a later count rebuild cannot finish. Snapshots are independent charged copies; a later live update must not modify a frozen copy. Grouped record/outcome masks retain enough identities to reconstruct every unresolved pair.

ORDER0/1/2 readers use the exact same supplied active table and ordinary typed history. They cannot import unassimilated queued observations. The generic reader bulk-copies the exact frozen T once and rebuilds its count table once, with its source hash recorded; it does not perform gratuitous repeated online fitting. Their fitting and prediction are diagnostic development components; they are not treatment arms and never return results to acquisition in043.

## N3 implementation contract

Post-warm-up counter `t_next=t+1` determines coverage and validation offsets. Proposal construction happens before the new trial reservation; persist the counter immediately before its reservation attempt. A proposal-construction failure has not reserved a new experiment. A terminal failed reservation remains recorded. This is an explicit prospective completion of the original wording.

The fixed mutation traversal is insertion, deletion, replacement and adjacent swap, with increasing positions and macro acquisition order. Flatten literal words, reject empty/overlength results, retain every parent/derivation and deduplicate only child words. Maximal parent mean determines priority; shorter word, numeric word order and parent acquisition index break ties. Fragment promotion uses length/word order. FEEDBACK_NULL suppresses operative utility and promotion; direct COVERAGE avoids proposal construction and receives its actual cost savings. Actual measurements are not imputed to a more expensive implementation.

Validation status precedence is: incomplete trial/block has no credit; complete block with any nonnumeric prediction is UNAVAILABLE; complete numeric block with no new trial predicate has available zero credit; otherwise use exact rational mean Brier improvement. A fresh predicate selected during delayed validation does not earn credit for the preceding trial. Both before/after copies remain frozen throughout validation. A completed physical trace and an incomplete fit have separate flags.

An environmental stop permits finalization and chronological assimilation of its completed validation prefix under the remaining computation allowance. A computation refusal is terminal for this development acquisition; it cannot be evaded by proceeding with cheaper fitting or proposal operations. Raw evidence and pending queues remain available for inspection. A later resume cannot replenish a scientific acquisition budget. The implemented acquisition entry point does not silently resume after a stop. An issued action whose response/assimilation is interrupted is retained as a pending encounter; this edge is an explicit remaining live-inventory admission dependency, not evidence that its token vanished.

## Implemented work and storage ruler

`scripts/accounting043.py` defines the deterministic DEVELOPMENT_METER_043 convention. It counts explicit named abstract operations and emitted bytes, with declared operand-bit charges. It is **not** a count of Python instructions or a hardware-independent elapsed-time guarantee. Host interpreter, counter apparatus, garbage collection and operating-system overhead remain included in physical wall/CPU/RSS measurements but are not recursively charged as new scientific operations.

`charge(category, units, bits)` debits `units * max(1,bits)` before its guarded operation. Word/node/index/control and copy steps are named in the module call sites. Bitset work uses operand-width charges; grouped count arithmetic records integer widths. Exact rational operations charge schoolbook cross products plus explicit Euclidean reduction work. N3 also charges its comparison, scoring and utility bookkeeping. These declared aggregate prices are an inspectable workload convention; they are not a claim that each interpreter suboperation has been individually audited.

Canonical logical storage uses ASCII JSON with sorted keys and fixed compact separators. Integer tokens and tuple/list state use explicit schemas. The codec rejects nonfinite/floating scientific state; rational values have exact numerator/denominator representation. Module state exporters determine the corresponding schema, including explicit pair/group, cursor, count and provenance fields. Numeric AST/word comparison uses numeric tuples, not decimal JSON lexical ordering. Codec traversal and emitted bytes are charged; canonical ordering uses the documented conservative serialization charge. That charge is a declared accounting rule, not the actual CPython sorting-comparison trace.

Owners identify separately stored state or workspace. `reserve` checks the new logical retained-byte total before a guarded external action or scientific state expansion; `retain` seals a complete canonical state size; `release` removes an owner's retained bytes. Snapshot copies are fully charged, with no unproved cross-owner sharing discount. A single-use prepaid release lease allows failed snapshot construction to relinquish only its reserved owner after a work refusal, without refunding work or making a new debit. Per-stage growth estimates are conservative development reservations, and their actual post-stage size is checked. Raw histories, syntax, counts, conflict records, cursors, proposal provenance, temporary copies and pending validation are retained in the relevant owner state.

Four quantities remain distinct: the last successfully sealed canonical payload, current owner reservations/high-water, process peak RSS and address-space ceiling. N1 exports whether its reservation is exact; a reserved capacity is not labeled an exact payload size. A logical reservation does not certify physical allocator use. Exact atomicity and coverage of every temporary/copy/provenance object have **not** been proved for all possible resource stops. The post-trial snapshot envelope is explicitly supplied and checked in development; its existence does not establish a complete-run memory bound. Consequently no043 meter total is promoted to scientific B_comp or B_mem.
